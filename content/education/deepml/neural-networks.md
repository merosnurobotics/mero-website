## A 가중치는 입력을 해석하는 값이다

신경망은 여러 계산 층을 이어 붙인 모델입니다. 각 층은 입력에 가중치(weight)를 곱하고 편향(bias)을 더한 뒤, 활성화 함수로 값을 바꿉니다. 가중치와 편향은 학습으로 바뀌는 **파라미터(parameter)**입니다.

입력이 하나인 계산은 다음처럼 읽을 수 있습니다.

**출력 = 입력 × 가중치 + 편향**

거리 센서의 비례 오차는 가중치로, 일정하게 더해진 오차는 편향으로 보정할 수 있습니다. 실제 관계가 더 복잡하면 여러 계산과 활성화 함수를 이어 사용합니다. 활성화 함수는 단순한 직선 관계를 넘어서는 표현을 가능하게 합니다.

![거리 보정 모델의 신경망 · 입력 1개, 은닉층 8개씩, 출력 1개](/home/user/MEROsite/private/education-assets/deepml/neural-network.png)

**MLP**는 숫자 벡터를 여러 층으로 처리하는 신경망입니다. **CNN**은 사진의 가까운 픽셀 묶음을 처리하는 계산을 사용합니다. 객체인식 모델은 이런 특징 계산에 종류나 영역을 출력하는 부분을 붙입니다. 구조 이름을 모두 외우기보다 입력과 출력의 모양을 먼저 확인합니다.

## B 틀린 정도를 손실로 표현한다

모델을 학습하려면 예측이 정답에서 얼마나 벗어났는지 숫자로 나타내야 합니다. 이 숫자가 **손실(loss)**입니다. 손실 함수는 문제의 출력 형식에 맞춰 정합니다.

| 출력 | 비교하는 것 | 자주 쓰는 손실의 역할 |
|---|---|---|
| 거리 같은 수치 | 예측 거리와 기준 거리 | 차이가 큰 예측에 더 큰 비용 |
| 물체 종류 | 클래스별 출력과 정답 클래스 | 정답 클래스에 낮은 점수를 주면 큰 비용 |
| 물체 영역 | 예측 영역과 정답 영역 | 잘못 포함하거나 놓친 픽셀에 비용 |

**기울기(gradient)**는 가중치를 조금 바꿀 때 손실이 어느 방향으로 변하는지 나타냅니다. **역전파(backpropagation)**는 출력에서 앞쪽 층으로 연결을 따라 이 기울기를 계산합니다. PyTorch의 `loss.backward()`가 이 계산을 맡습니다.

**옵티마이저(optimizer)**는 계산된 기울기로 가중치를 수정합니다. **학습률(learning rate)**은 수정하는 크기를 조절합니다. 너무 크면 손실이 크게 흔들릴 수 있고, 너무 작으면 개선이 느립니다. 역전파와 가중치 수정은 서로 다른 단계입니다.

## C 한 번의 학습 반복을 읽는다

배치(batch)는 한 번에 처리할 입력 묶음입니다. **에포크(epoch)**는 학습 데이터 전체를 한 차례 사용한 횟수입니다. 배치 하나를 처리하는 스텝(step)과 에포크는 데이터 크기에 따라 다릅니다.

```flow LR
입력 배치 -> 예측 계산: 현재 가중치 사용
예측 계산 -> 손실 계산: 정답과 비교
손실 계산 -> 기울기 계산: 역전파
기울기 계산 -> 가중치 수정: 옵티마이저
가중치 수정 -> 입력 배치: 다음 반복
```

## D 학습 곡선에서 개선과 이상 징후를 읽는다

학습 손실은 모델이 가중치를 맞춘 데이터에서의 오차입니다. 검증 손실은 가중치 수정에 사용하지 않은 데이터에서의 오차입니다. 둘을 함께 봐야 학습한 예시를 넘어서는 성능을 확인할 수 있습니다.

![합성 거리 보정 · 학습 데이터와 검증 데이터의 손실](/home/user/MEROsite/private/education-assets/deepml/training.png)

CPU에서 두 개의 은닉층을 가진 작은 신경망을 401회 학습했습니다. 세로축은 로그 눈금이며, 손실은 평균 제곱 오차입니다. 이 곡선은 실물 센서의 성능을 나타내지 않습니다.

| 관찰 | 먼저 확인할 것 |
|---|---|
| 학습·검증 손실이 함께 줄어듦 | 실제 사진이나 새로운 조건에서도 개선되는지 |
| 학습 손실만 줄고 검증 손실은 커짐 | 과적합·데이터 분리·모델 복잡도 |
| 처음부터 손실이 줄지 않음 | 정답 대응·입력 단위·학습률·출력 형식 |
| 손실에 NaN이 나타남 | 잘못된 입력·너무 큰 값·불안정한 계산 |

**과적합(overfitting)**은 학습 데이터에는 잘 맞지만 새 데이터에서는 성능이 떨어지는 현상입니다. 반복 횟수를 더 늘리는 것만으로 해결되지 않습니다. 다음 자료에서는 모델을 고를 데이터와 최종 평가에 쓸 데이터를 나눕니다.
