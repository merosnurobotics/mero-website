## A 로봇이 풀어야 할 문제부터 정한다

사진에서 사과를 찾는 일과 로봇의 균형을 잡는 일은 입력과 출력이 다릅니다. 학습을 시작하기 전에 **무엇을 받아 무엇을 내보낼지** 정해야 합니다. 이 둘을 연결하는 계산 규칙이 모델입니다.

| 동아리에서 하는 일 | 입력 | 출력 | 결과를 쓰는 곳 |
|---|---|---|---|
| 과일 종류 구분 | 물체 사진 | 사과·바나나 같은 종류 | 어떤 물체를 집을지 결정 |
| 객체 영역 분할 | 카메라 사진 | 물체를 차지하는 픽셀 영역 | 깊이와 합쳐 물체 좌표 계산 |
| 거리 보정 | 센서가 읽은 거리 | 보정한 거리 | 지도 위 위치 계산 |
| 한 발 서기 | 관절 각도·속도·몸통 기울기 | 관절 목표의 보정값 | 관절 제어기로 전달 |

딥러닝은 여러 층의 신경망으로 이 계산 규칙을 표현하고, 데이터로 그 안의 값을 맞추는 방법입니다. 강화학습은 행동의 결과에서 얻은 보상으로 제어 규칙을 배우는 방법입니다. 신경망을 강화학습의 제어 규칙으로 사용할 수도 있습니다.

```flow LR
센서 입력 -> 전처리: 크기와 단위를 맞춘다
전처리 -> 모델: 숫자 배열
모델 -> 결과 해석: 예측 값
결과 해석 -> ROS 노드: 종류와 좌표 또는 관절 목표
```

기하 계산으로 정확히 풀 수 있는 문제는 그 계산을 그대로 사용해도 됩니다. 객체의 마스크를 찾는 데 신경망을 쓰고, 마스크와 깊이를 지도 좌표로 바꾸는 데 좌표 변환을 쓰는 식입니다.

## B 사진과 센서 값을 숫자로 읽는다

**텐서(tensor)**는 숫자를 담은 배열입니다. 거리 하나는 숫자 하나로, 관절 여러 개의 각도는 벡터로, 사진은 높이·너비·색상 채널을 가진 배열로 표현합니다. 여러 입력을 묶은 배치(batch)도 텐서입니다.

예를 들어 224×224 RGB 사진 한 장은 색상 값 150,528개를 담습니다. 같은 사진도 라이브러리에 따라 배열 순서가 다릅니다. PyTorch 이미지 모델은 흔히 **배치·채널·높이·너비** 순서를 사용합니다.

| 확인할 항목 | 카메라 입력 | 관절 입력 |
|---|---|---|
| 모양(shape) | 채널 수·사진 크기·배치 수 | 관절 수·관절 순서 |
| 단위와 범위 | 0~255 또는 정규화된 범위 | rad 또는 degree, rad/s |
| 순서 | RGB 또는 BGR | 학습 때 정한 관절 순서 |
| 빠진 값 | 손상된 사진·가려진 영역 | 센서 누락·오래된 측정값 |

**정규화(normalization)**는 학습 때 정한 기준으로 숫자 범위를 맞추는 처리입니다. 모든 모델이 같은 정규화를 쓰지는 않습니다. 이미 모델의 입력 처리에 포함돼 있다면 다시 적용하지 않습니다.

ROS 토픽에서 받은 값도 바로 모델에 넣기 전에 단위·순서·측정 시각을 맞춥니다. 관절 개수만 같아도 순서가 바뀌면 다른 자세를 입력한 셈이 됩니다.

## C 데이터에는 무엇을 배우게 할지 담겨 있다

**지도학습(supervised learning)**은 입력과 정답을 짝지어 학습합니다. 사과 사진에는 사과라는 종류를, 객체 사진에는 경계 상자나 마스크를, 거리 측정값에는 기준 장비로 잰 거리를 붙입니다. 이 정답을 라벨(label)이라고 합니다.

| 문제 | 필요한 정답 | 정답에서 생기기 쉬운 문제 |
|---|---|---|
| 분류 | 사진의 종류 | 사과를 바나나로 잘못 지정 |
| 탐지 | 종류와 경계 상자 | 작은 물체를 누락 |
| 영역 분할 | 종류와 픽셀 영역 | 물체 경계가 실제와 다름 |
| 수치 예측 | 기준 측정값 | 단위나 측정 시각이 어긋남 |

데이터의 양뿐 아니라 **로봇이 실제로 보게 될 조건**이 중요합니다. 가까운 밝은 사진만 학습하면 멀리 있는 물체나 어두운 경기장에서 실패할 수 있습니다. 각도·거리·조명·배경·가림을 함께 기록하면 실패 원인을 찾기 쉽습니다.

합성 데이터는 사진과 정답을 함께 만들기 좋습니다. 다만 렌더링 화면과 실제 카메라의 노이즈·반사·그림자는 다릅니다. 합성 데이터로 시작하더라도 실제 사진을 별도로 남겨 모델을 확인합니다.

## D 학습과 추론은 다른 단계다

**학습(training)**에서는 예측을 정답과 비교하고 모델의 가중치를 바꿉니다. **추론(inference)**에서는 학습된 가중치로 새 입력의 결과를 계산합니다. 카메라가 새 사진을 보내는 것만으로 모델이 자동으로 더 잘 배우지는 않습니다.

```flow LR
사진과 정답 -> 학습 프로그램: 예측과 정답을 비교
학습 프로그램 -> 저장된 가중치: 반복해서 수정
저장된 가중치 -> 로봇의 모델: 같은 구조에 불러온다
새 카메라 사진 -> 로봇의 모델: 학습 때와 같은 전처리
로봇의 모델 -> 예측 결과: 종류와 영역
```

파일 이름이 `best.pt`라고 해서 어느 모델에서나 읽을 수 있는 것은 아닙니다. 모델 구조·클래스 순서·입력 크기·전처리도 함께 맞아야 합니다. 학습 기록에는 데이터 버전과 가중치 파일을 함께 남깁니다.

이제 신경망 안에서 어떤 값이 바뀌는지 살펴봅니다. 여기서 정한 입력·정답·출력 구분은 [기존 객체인식 자료](/education/object-recognition/synthetic-data)에서도 그대로 사용합니다.
