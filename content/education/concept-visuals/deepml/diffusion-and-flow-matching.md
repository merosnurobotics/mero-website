## many-valid-answers | 왼쪽과 오른쪽의 평균은 장애물 방향일 수 있습니다

```flow LR
목표 뒤 장애물 -> 왼쪽 우회
목표 뒤 장애물 -> 오른쪽 우회
왼쪽 우회 -> 목표 도달
오른쪽 우회 -> 목표 도달
```
두 경로는 모두 타당합니다. 같은 시점의 명령을 단순 평균하면 장애물을 향할 수 있다는 개념 예시입니다.

## diffusion | 관측 조건을 보면서 행동 후보를 다듬습니다

```flow LR
초기 잡음 -> 반복 갱신 -> 행동 묶음
현재 관측 -> 반복 갱신
반복 갱신 -> 반복 갱신: 반복
```
그림의 반복은 샘플 생성 과정입니다. 실제 로봇이 잡음 행동을 먼저 실행한다는 뜻이 아닙니다.

## flow-matching | 두 생성 방법에서 읽을 공통 질문

| 읽을 항목 | 확산 계열 | Flow Matching 계열 |
|---|---|---|
| 시작 | 잡음 등 초기 분포 | 단순한 초기 분포 |
| 학습 신호 | 잡음 제거와 관련한 예측 | 경로를 따른 이동 방향 |
| 생성 | 단계적으로 샘플 갱신 | 학습한 방향으로 샘플 이동 |
| 로봇 적용 | 행동의 단위와 실행 지연 확인 | 행동의 단위와 실행 지연 확인 |

개념 비교입니다. 구현마다 예측 대상과 샘플러가 달라집니다.
