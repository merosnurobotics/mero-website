## supervision | 정답 신호는 어디에서 올까

```flow LR
라벨 없는 이미지 -> 변형 관측 A
라벨 없는 이미지 -> 변형 관측 B
변형 관측 A -> 표현 관계 학습
변형 관측 B -> 표현 관계 학습
표현 관계 학습 -> 후속 작업 평가
```
같은 원본의 두 관측을 연결하는 한 가지 예입니다. 가린 부분을 예측하는 등 다른 자기지도 과제도 있습니다.

## views-and-augmentation | 바꿔도 되는 차이와 남겨야 할 차이

| 작업 | 허용하기 쉬운 변화 | 먼저 점검할 변화 |
|---|---|---|
| 종류 검색 | 약한 밝기 변화 | 물체가 사라질 정도의 자르기 |
| 색상 분류 | 배경 이동 | 빨강을 파랑으로 바꾸기 |
| 손잡이 접근 | 작업과 무관한 무늬 | 손잡이 방향을 뒤집기 |

증강 후에도 과제의 정답이 유지되는지 먼저 확인합니다.

## evaluate-representation | 고정해서 읽기와 함께 바꾸기는 다른 실험입니다

```flow LR
사전학습 특징 -> 본체 고정
사전학습 특징 -> 전체 미세조정
본체 고정 -> 분류기 학습
전체 미세조정 -> 새 환경 적응
분류기 학습 -> 새 촬영일 평가
새 환경 적응 -> 새 촬영일 평가
```
두 실험에서 라벨 수와 평가 묶음을 맞춥니다. 학습 장면과 거의 같은 프레임을 시험에 넣지 않습니다.
