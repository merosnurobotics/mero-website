## local-patterns | 규칙은 공유하고 검사 위치는 옮깁니다

```flow LR
같은 필터 -> 왼쪽 창
같은 필터 -> 오른쪽 창
왼쪽 창 -> 특징 맵
오른쪽 창 -> 특징 맵
```
두 위치를 예로 들었습니다. 실제로는 창을 옮기는 모든 위치에서 같은 가중치를 사용합니다. 위치마다 별도 검출 규칙을 외우는 구조와 다릅니다.

## resolution | 작은 나사는 어디에서 사라질까

| 확인 위치 | 눈여겨볼 것 | 바꿔 볼 선택 |
|---|---|---|
| 원본 카메라 | 나사가 충분한 픽셀을 차지하는가 | 촬영 거리와 시점 |
| 축소된 입력 | 나사와 배경이 구분되는가 | 입력 크기와 관심 영역 |
| 중간 특징 | 작은 위치 차이가 남는가 | 축소 비율과 출력 구조 |
| 실행 결과 | 검출 개선이 지연을 늘리는가 | 정확도와 처리 시간 비교 |

## backbone | 특징은 공유해도 출력은 작업마다 다릅니다

```flow LR
이미지 -> CNN 특징
CNN 특징 -> 분류 head -> 물체 이름
CNN 특징 -> 검출 head -> 위치 상자
```
CNN을 쓴다는 말만으로 출력 형식은 정해지지 않습니다. 집기에는 필요한 위치 정보를 내는 출력이 있어야 합니다.
