## alignment-and-clip | 이미지와 문장은 어떻게 비교할까

```flow LR
컵 이미지 -> 이미지 표현 -> 유사도 비교
후보 설명 -> 텍스트 표현 -> 유사도 비교
유사도 비교 -> 관련 설명 선택
```
유사도는 후보 설명과 이미지의 관련성을 나타냅니다. 선택된 이름만으로 집을 좌표를 얻지는 못합니다.

## vlm-and-grounding | 같은 장면에서 물어보는 질문이 달라집니다

| 질문 | 필요한 출력 | 이어질 작업 |
|---|---|---|
| 무엇이 보이는가 | 장면 설명 | 상황 이해 |
| 어느 컵인가 | 상자 또는 영역 | 목표 지정 |
| 어디로 손을 보낼까 | 로봇 기준 위치 | 접근 계획 |
| 잡혔는가 | 관측에 근거한 결과 | 재시도 판단 |

## robot-bridge | 말에서 행동까지의 연결을 빠짐없이 봅니다

```flow LR
언어 목표 -> 장면 속 대상 -> 공간 위치 -> 행동 명령 -> 결과 확인
```
이 역할들이 하나의 모델에 통합되더라도 각 연결이 작동하는지는 따로 점검할 수 있습니다.
