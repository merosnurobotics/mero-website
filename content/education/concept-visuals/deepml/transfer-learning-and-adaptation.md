## pretraining | 재사용하는 것과 새로 맞추는 것

```flow LR
사전학습 모델 -> 재사용할 특징
새 환경 데이터 -> 작업별 적응
재사용할 특징 -> 작업별 적응
작업별 적응 -> 새 장면 평가
```
모델 이름이 같아도 카메라 전처리, 출력 형식, 물체 분포가 달라지면 결과가 달라집니다.

## freeze-or-finetune | 얼마나 바꿀지부터 비교합니다

| 방법 | 바꾸는 부분 | 주로 확인할 점 |
|---|---|---|
| 본체 고정 | 작은 출력기 | 필요한 정보가 기존 특징에 있는가 |
| 전체 미세조정 | 본체와 출력기 | 과적합과 이전 능력 저하 |
| LoRA | 추가한 저차원 변화 | 적용한 층과 적응 용량 |

어느 방법이 유리한지는 데이터 수와 새 작업의 차이에 달려 있습니다.

## lora | 원래 변환에 학습 경로를 더합니다

```flow LR
입력 -> 고정 변환 -> 출력 합산
입력 -> 학습 경로 -> 출력 합산
```
개념적으로 원래 가중치의 출력과 학습한 변화의 출력을 합칩니다. 그림은 행렬 크기를 나타내지 않습니다.
