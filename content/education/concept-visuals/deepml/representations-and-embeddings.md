## representation | 사진과 판단 사이에 무엇이 들어갈까

```flow LR
컵 사진 -> 특징 추출기 -> 임베딩
임베딩 -> 종류 분류
임베딩 -> 유사한 컵 검색
```
픽셀, 중간 표현, 최종 출력은 서로 다른 역할입니다. 특징 추출기는 다음 판단에 필요한 정보를 남깁니다.

## objective | 같은 사진에서도 남겨야 할 정보가 다릅니다

| 목적 | 유지할 차이 | 무시해도 되는 변화 |
|---|---|---|
| 컵 종류 검색 | 형태와 범주 | 작업과 무관한 배경 |
| 손잡이 접근 | 방향과 주변 공간 | 작업과 무관한 무늬 |
| 손끝 위치 결정 | 위치와 거리 | 물체 이름의 표현 방식 |

전체 이미지 벡터와 공간별 특징은 서로 다른 정보를 쉽게 꺼내 쓰게 합니다.

## inspect | 배경에 속았는지 확인하는 비교

```flow LR
질의 사진 -> 이웃 검색 -> 결과 비교
결과 비교 -> 배경 변경
결과 비교 -> 물체 변경
```
배경 변경: 물체를 그대로 두고 배경을 바꿉니다. 물체 변경: 배경을 그대로 두고 물체를 바꿉니다.

두 비교에서 순위가 어떻게 바뀌는지 봅니다. 보기 좋은 군집 그림만으로 작업 적합성을 판단하지 않습니다.
