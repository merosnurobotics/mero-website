## coupled-body | 상자를 들면 팔의 목표가 발의 지지와 연결됩니다

```flow LR
상자 위치 -> 팔과 몸통
상자 하중 -> 팔과 몸통
팔과 몸통 -> 몸 전체 균형
몸 전체 균형 -> 발의 지지
```

같은 물체도 몸에서 멀리 들면 부담이 달라집니다. 손끝 목표만으로 몸 전체의 실행 가능성을 판단하지 않습니다.

## policy-interface | 관절 목표를 출력하는 정책의 한 가지 연결 예

```flow LR
관측 -> 학습 정책
학습 정책 -> 관절 목표
관절 목표 -> 하부 제어기
하부 제어기 -> 구동 명령
```

가능한 구조 중 하나입니다. 정책이 토크나 발 위치, 기본 행동의 보정을 출력하는 구조와 구분합니다.

## objectives-and-constraints | 작업 목표와 실행 조건을 분리합니다

| 요구 | 역할의 예 | 충돌할 때 볼 것 |
| --- | --- | --- |
| 상자 수평 유지 | 작업 목표 | 보행 속도와 우선순위 |
| 몸통 자세 | 작업 목표 | 도달 범위 |
| 관절·접촉 한계 | 실행 조건 | 현재 하중의 가능성 |

실제 제어기의 비용·제약 구성은 다를 수 있습니다. 무엇을 양보하고 무엇을 유지하는지 명시합니다.
