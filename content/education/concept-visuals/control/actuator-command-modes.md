## commands | 같은 숫자라도 명령 모드가 바뀌면 행동이 달라집니다

| 모드 | 요청하는 것 | 함께 확인할 상태 |
| --- | --- | --- |
| 위치 | 도달할 각도 | 각도와 추적 속도 |
| 속도 | 회전하는 빠르기 | 속도와 이동 범위 |
| 토크 | 돌리는 힘 | 자세·속도·접촉 |

표의 모드는 제어 권한의 차이를 뜻합니다. 어느 모드든 장치의 단위와 방향을 먼저 확인합니다.

## inner-loop | 위치 명령 아래에서 내부 제어가 일을 합니다

```flow LR
상위 목표 -> 위치 명령
위치 명령 -> 내부 제어기
내부 제어기 -> 모터
모터 -> 내부 센서
내부 센서 -> 내부 제어기
```

흔한 위치 구동기의 개념도입니다. 실제 내부 루프와 제한은 장치별 문서에서 확인합니다.

## measurement-contract | 센서가 달린 위치에 따라 보이는 움직임이 다릅니다

```flow LR
모터 -> 전달계
전달계 -> 관절 출력
모터 -> 모터 엔코더: 회전 측정
관절 출력 -> 출력 엔코더: 회전 측정
```

전달계에 유격이나 변형이 있으면 두 엔코더가 같은 순간에 다른 움직임을 볼 수 있습니다.
