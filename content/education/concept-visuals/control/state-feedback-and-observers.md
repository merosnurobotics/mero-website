## state | 같은 각도라도 속도가 다르면 다음 순간이 다릅니다

```tree
같은 기울기
  넘어지는 중 | 제동이 필요할 수 있음
  돌아오는 중 | 과한 보정을 피해야 함
  정지 상태 | 외력과 균형 조건 확인
```

그림은 같은 위치만 보고 동일한 명령을 고르면 놓칠 수 있는 차이를 보여 줍니다.

## observer | 모델 예측과 센서 근거를 연결하는 관측기

```flow LR
이전 추정과 명령 -> 상태 예측
상태 예측 -> 측정 비교
새 센서 값 -> 측정 비교
측정 비교 -> 보정된 추정
보정된 추정 -> 다음 제어
```

추정값은 직접 측정값과 다릅니다. 예측과 측정의 차이가 지속되면 모델·편향·시각도 조사합니다.

## lqr-and-limits | 좋은 모델 결과를 장치에서 확인할 항목

| 설계 요소 | 뜻 | 장치에서 볼 것 |
| --- | --- | --- |
| 상태 비용 | 어떤 오차를 줄일까 | 위치·속도 반응 |
| 입력 비용 | 큰 명령을 얼마나 피할까 | 포화와 힘 부족 |
| 선형 모델 | 어느 근처를 설명할까 | 큰 동작과 접촉 변화 |

LQR의 비용 설정과 실제 장치의 한계를 구분해서 읽습니다. 관측기의 오차와 지연도 함께 확인합니다.
