## stability-and-response | 가까이 머무는 성질에 수렴 조건을 더합니다

```tree
평형점 주변의 반응
  안정성 | 가까이 출발하면 가까이 유지
    점근 안정성 | 시간이 지나 평형점으로 수렴
  응답 품질 | 지나침·정착 시간·잔류 오차
```

안정성과 응답 품질은 서로 다른 질문입니다. 안정적이라는 말만으로 빠른 회복을 뜻하지는 않습니다.

## local-recovery | 회복 영역은 각도만으로 정해지지 않습니다

```flow LR
초기 각도 -> 초기 상태
초기 속도 -> 초기 상태
초기 상태 -> 폐루프 동작
폐루프 동작 -> 회복 여부
```

같은 기울기라도 빠르게 넘어지는 상태와 되돌아오는 상태는 다릅니다. 흡인 영역은 상태 공간에서 정의합니다.

## evidence-and-limits | 시험 결과와 증명이 각각 말해 주는 범위

| 근거 | 말할 수 있는 것 | 남는 확인 |
| --- | --- | --- |
| 반복 실험 | 시험 조건에서의 결과 | 시험하지 않은 상태 |
| 모델 해석 | 가정 아래의 성질 | 실제 장치와 가정의 차이 |
| 하중·지연 변화 | 변화 범위의 강인성 | 범위 밖 동작 |

초기 각도·속도·하중·지연의 범위를 함께 남겨야 다른 설정과 공정하게 비교할 수 있습니다.
