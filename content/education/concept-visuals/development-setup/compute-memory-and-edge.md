## memory | 파일보다 커지는 실행 메모리

```tree
실행 메모리
  모델 가중치
  입력 데이터
  중간 결과
  임시 작업 공간
```

학습에서는 기울기와 최적화 상태도 추가됩니다. 도식은 용량 비율을 나타내지 않습니다.

## latency-throughput | 로봇의 반응 시간은 전체 경로에서 나옵니다

```flow LR
촬영 -> 전처리
전처리 -> 모델 추론
모델 추론 -> 명령 전송
명령 전송 -> 실제 구동
```

추론 시간 하나와 촬영부터 동작까지의 시간을 따로 측정하세요.

## edge-vla | 로봇 내부와 서버 실행에서 달라지는 조건

| 관점 | 로봇 내부 추론 | 서버 추론 |
|---|---|---|
| 계산 자원 | 탑재 장치의 한계 | 서버 자원 사용 |
| 연결 | 외부 의존 감소 | 통신 상태 영향 |
| 제약 | 전력·열·메모리 | 지연·대역폭 |
| 검증 | 실제 장치에서 측정 | 왕복 경로까지 측정 |
