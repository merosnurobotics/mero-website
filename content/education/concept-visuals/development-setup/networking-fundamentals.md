## addresses | 통신 목적지는 주소와 포트로 찾습니다

```flow LR
클라이언트 -> 목적지 장치: 주소
목적지 장치 -> 서버 프로그램: 포트
서버 프로그램 -> 응답
```

localhost는 지금 명령을 실행한 장치 자신을 가리킵니다.

## boundaries | 컨테이너 안팎의 주소를 따라가기

```flow LR
노트북 -> 호스트 주소: 접근
호스트 주소 -> 포트 연결
포트 연결 -> 컨테이너 서버
```

안쪽에서 성공한 요청과 바깥에서 성공한 요청은 다른 경로의 증거입니다.

## latency | 연결 상태와 데이터 품질은 다른 질문

| 관점 | 질문 | 관측값 |
|---|---|---|
| 연결 | 목적지에 도달하나 | 연결·응답 |
| 처리량 | 얼마나 많이 보내나 | 시간당 데이터 |
| 지연 | 얼마나 기다리나 | 전달·처리 시간 |
| 최신성 | 얼마나 오래된 값인가 | 측정 시각의 나이 |
