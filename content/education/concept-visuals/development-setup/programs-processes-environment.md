## program-process | 같은 파일에서 서로 다른 실행이 나옵니다

```flow LR
코드 파일 -> 프로세스 A: 실행 1
코드 파일 -> 프로세스 B: 실행 2
프로세스 A -> 상태 A
프로세스 B -> 상태 B
```

프로세스마다 실행 시점과 메모리 상태가 다릅니다.

## execution-context | 실행 조건을 한 묶음으로 기록하기

```tree
실행 한 번
  코드 버전 | 무엇을 실행했나
  인자·환경 | 어떤 조건인가
  작업 폴더 | 어디서 시작했나
  입력 데이터 | 무엇을 읽었나
```

## lifecycle | 켜짐부터 종료까지 확인할 상태

```timeline v
시작 | 프로세스 생성 | 실제로 시작했는지 확인
준비 | 장치·설정 확인 | 작업 조건이 갖춰졌는지 확인
작업 | 데이터 처리 | 결과가 새로 갱신되는지 확인
종료 | 저장·자원 정리 | 마지막 결과와 종료 상태 확인
```
