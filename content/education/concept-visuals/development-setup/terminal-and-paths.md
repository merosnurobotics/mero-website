## terminal-shell | 명령 한 줄이 프로그램이 되기까지

```flow LR
터미널 -> 셸: 입력
셸 -> 프로그램: 해석·시작
프로그램 -> 실행 결과: 처리
```

셸은 현재 작업 폴더와 환경을 새 프로그램에 전달합니다.

## working-directory | 같은 상대 경로도 출발점이 다릅니다

```tree
project/
  images/
    cup.png | 실제 입력
  scripts/
    analyze.py | 프로그램
```

프로젝트 최상위에서는 `images/cup.png`를 찾습니다. `scripts` 안에서 시작하면 같은 문자열이 다른 위치를 가리킵니다.

## paths-and-files | 파일 오류를 세 층으로 나누기

| 질문 | 뜻 | 확인 대상 |
|---|---|---|
| 경로가 맞는가 | 위치의 표현 | 작업 폴더·경로 |
| 파일이 있는가 | 대상의 존재 | 실제 파일 시스템 |
| 읽을 수 있는가 | 접근 가능성 | 사용자·권한 |

절대 경로도 다른 컴퓨터의 같은 파일을 보장하지는 않습니다.
