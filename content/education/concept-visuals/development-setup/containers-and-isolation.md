## image-container | 같은 환경 틀에서 여러 실행을 시작합니다

```flow LR
컨테이너 이미지 -> 실행 A: 시작
컨테이너 이미지 -> 실행 B: 시작
실행 A -> 임시 상태 A
실행 B -> 임시 상태 B
```

이미지 버전이 같아도 실행 인자와 연결한 데이터는 다를 수 있습니다.

## persistent-data | 실행의 수명과 데이터의 수명을 나누기

```flow LR
호스트 입력 -> 컨테이너: 읽기
컨테이너 -> 보관 폴더: 결과
보관 폴더 -> 다음 실행: 재사용
```

컨테이너를 다시 만들어도 필요한 데이터는 별도 보관 위치에 남도록 구성합니다.

## robot-connections | 컨테이너 경계에서 확인할 연결

| 자원 | 호스트에서 확인 | 컨테이너에서 확인 |
|---|---|---|
| USB·시리얼 | 장치 인식 | 연결·권한 |
| GPU | 드라이버 | 실행 지원 |
| 네트워크 | 목적지·포트 | 안팎의 주소 |
| 파일 | 실제 보관 위치 | 경로·읽기 쓰기 |
