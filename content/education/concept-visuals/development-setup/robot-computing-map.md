## machines | 장치별로 나누어 보는 로봇의 계산 역할

각 상자는 가능한 배치의 예입니다. 모든 로봇이 네 장치를 전부 쓰는 것은 아닙니다.

```flow LR
노트북 -> 로봇 컴퓨터: 목표
로봇 컴퓨터 -> 제어기: 명령
학습 서버 --> 로봇 컴퓨터: 정책
```

## responsibility | 컵을 옮길 때 정보가 바뀌는 순서

```flow LR
카메라 -> 물체 인식: 이미지
물체 인식 -> 작업 판단: 컵 위치
작업 판단 -> 모터 제어: 목표
```

화살표를 건널 때 데이터의 의미가 바뀝니다. 위치에는 좌표 기준도 필요합니다.

## debug-boundaries | 멈춘 구간을 찾는 네 가지 질문

| 경계 | 확인할 증거 | 다음 점검 |
|---|---|---|
| 센서 출력 | 새 측정 시각 | 장치와 읽기 |
| 판단 입력 | 실제 수신값 | 연결과 타입 |
| 목표 출력 | 유효한 목표 | 판단 조건 |
| 제어기 입력 | 수신·실행 상태 | 구동 조건 |
