## types-and-meaning | 로봇에서 숫자의 의미를 완성하는 정보

```tree
위치 데이터
  값 | x·y·z
  단위 | 미터 등
  좌표계 | 카메라·로봇 기준
  시각 | 언제 측정했나
```

숫자 배열의 길이가 맞아도 좌표 기준이 없으면 행동 목표로 해석하기 어렵습니다.

## serialization | 파일 읽기와 의미 검사는 별도 단계

```flow LR
JSON·YAML -> 파싱: 문법
파싱 -> 계약 검사: 의미
계약 검사 -> 프로그램 입력: 통과
```

파싱 성공은 필수 항목과 허용 범위까지 맞다는 뜻이 아닙니다.

## configuration | 설정 변경 전에 확인할 세 가지

| 항목 | 예시 질문 | 기록할 내용 |
|---|---|---|
| 기본값 | 생략하면 무엇을 쓰나 | 기본값·필수값 |
| 우선순위 | 파일과 인자가 다르면 | 최종 적용 규칙 |
| 적용 시점 | 실행 중 바로 바뀌나 | 재시작·갱신 조건 |
