## snapshot-and-run | 실험을 되살리는 네 가지 조건

```tree
실험 기록
  코드 | 커밋·미기록 변경
  데이터 | 원본·버전
  환경 | 실행기·라이브러리
  설정 | 명령·난수 조건
```

같은 커밋은 같은 실험을 위한 조건의 일부입니다.

## data-and-artifacts | 결과 파일에도 생성 경로가 있습니다

```flow LR
원본 데이터 -> 전처리 결과: 변환
전처리 결과 -> 학습 모델: 학습
학습 모델 -> 평가 결과: 검증
```

각 화살표에 코드 버전과 설정을 연결하면 결과의 출처를 추적할 수 있습니다.

## reproduce | 처음 맡은 팀원의 재현 점검표

| 순서 | 문서에 필요한 것 | 확인 결과 |
|---|---|---|
| 준비 | 환경·시작 폴더 | 실행기 선택 |
| 입력 | 샘플과 위치 | 파일 읽기 |
| 실행 | 명령·설정 | 정상 처리 |
| 비교 | 기대 출력·허용 차이 | 재현 여부 |
