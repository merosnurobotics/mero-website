## reality-gap | 실제 동작을 바꾸는 차이는 어디에 있을까

```tree
Reality gap
  물리 | 마찰, 질량, 접촉
  구동 | 지연, 토크 한계, 영점
  관측 | 조명, 깊이 오차, 가림
  실행 | 제어 주기, 초기화, 복구
```
사실적인 렌더링이 물리와 실행 시간까지 맞춰 주지는 않습니다.

## randomization | 관측한 현실 차이로 학습 범위를 정합니다

```flow LR
실제 조건 측정 -> 변화 범위 설정 -> 여러 환경 학습 -> 별도 실제 평가
별도 실제 평가 -> 실패 원인 점검
```
랜덤화 범위를 무작정 넓히기보다 실제로 중요한 변화와 남아 있는 실패를 연결합니다.

## evaluation-set | 같은 성공률도 시험 내용이 다를 수 있습니다

| 시험 | 바꾸는 것 | 고정할 것 |
|---|---|---|
| 위치 변화 | 초기 물체 위치 | 물체 종류와 정책 |
| 물체 변화 | 보지 못한 제품 | 성공 정의와 실행 시간 |
| 조명 변화 | 밝기와 그림자 | 카메라 전처리 |
| 반복 안정성 | 반복 횟수와 시간 | 초기화 방식 |

성공 횟수와 전체 시도 수를 함께 남깁니다. 한 번의 시연은 이 비교를 대신하지 못합니다.
