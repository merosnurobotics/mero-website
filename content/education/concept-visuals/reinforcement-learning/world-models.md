## prediction | 행동 선택과 결과 예측은 다른 질문입니다

```flow LR
현재 관측 -> 정책 -> 후보 행동
현재 관측 -> 월드 모델
후보 행동 -> 월드 모델 -> 예상 다음 상태
```
월드 모델의 예측은 실제 관측을 대신할 수 있는지 평가해야 합니다.

## planning-learning | 예측을 사용하는 두 경로

```tree
월드 모델 활용
  실행 때 계획 | 후보를 예측하고 첫 행동 실행
    새 관측으로 다시 계획
  학습 때 상상 | 가상 경험으로 정책 개선
    실제 환경에서 개선 여부 평가
```
실행 계산 시간과 모델 오차의 영향이 두 경로에서 다르게 나타날 수 있습니다.

## model-errors | 어떤 예측 오차가 행동을 망칠까

| 예측 장면 | 확인할 정보 | 실패 가능성 |
|---|---|---|
| 컵을 잡는 순간 | 접촉과 미끄러짐 | 색은 자연스러워도 집기 실패 |
| 장애물 옆 이동 | 충돌과 위치 | 가상의 지름길 선택 |
| 긴 미래 예측 | 오차 누적 | 끝 상태를 과신 |

모델 속 보상과 실제 성공을 따로 기록합니다.
