## specification | 작업 문장을 확인 가능한 사건으로 바꿉니다

```flow LR
책상 정리 -> 목표 상자에 넣기 -> 손을 놓기 -> 안정적으로 남기
```
개념 예시입니다. 물체가 상자를 잠깐 통과한 것과 놓은 뒤 정리된 상태를 구분합니다.

## shaping | 중간 점수와 최종 성공을 따로 기록합니다

| 기록할 항목 | 유용한 이유 | 의심할 상황 |
|---|---|---|
| 목표까지 거리 | 진행 방향 확인 | 가까워졌다 멀어지며 점수 반복 |
| 들어 올림 | 집기 단계 확인 | 들기만 하고 운반하지 않음 |
| 최종 배치 | 작업 완료 확인 | 점수는 높지만 물체가 떨어짐 |

중간 보상은 실제 성공과 함께 해석해야 합니다.

## learned-reward | 사람의 비교도 검증할 학습 데이터입니다

```flow LR
두 실행 영상 -> 사람의 선호 -> 보상 모델 -> 정책 학습 -> 별도 성공 평가
```
영상에 보이지 않는 충격이나 실패는 비교에서 누락될 수 있습니다. 학습한 보상만으로 실제 성공을 대신하지 않습니다.
