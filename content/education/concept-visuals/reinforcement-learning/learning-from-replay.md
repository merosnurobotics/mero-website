## who-collected | 정책이 바뀌어도 기록의 출처는 남습니다

| 기록 | 확인할 정보 | 쓰임새 |
|---|---|---|
| 현재 정책의 실행 | 수집 당시 정책 버전 | 최근 행동 분포에 맞춘 갱신 |
| 이전 정책의 실행 | 시간과 환경 설정 | 재사용 가능한 경험 |
| 사람의 시연 | 조종 방식과 행동 단위 | 초기 행동 또는 별도 학습 자료 |

On과 off는 네트워크 연결 상태를 뜻하지 않습니다.

## ppo | 최근 경험을 모으고 정책을 갱신합니다

```flow LR
현재 정책 -> 경험 묶음 수집 -> 제한된 정책 갱신 -> 새 정책
새 정책 -> 다음 경험 수집
```
PPO도 한 경험 묶음으로 여러 번 최적화할 수 있습니다. 오래된 모든 경험을 계속 섞는 방식과는 구분합니다.

## replay | 저장소에서 다시 꺼내 배우는 경로

```flow LR
로봇 실행 -> 경험 저장소
경험 저장소 -> 경험 샘플 -> 가치와 정책 갱신
가치와 정책 갱신 -> 로봇 실행
```
SAC 같은 방법의 개념 흐름입니다. 저장소의 양보다 실패 복구와 조건 변화가 포함되는지 함께 봅니다.
