## pairs | 시연에서 같은 시점을 묶어 기록합니다

```flow LR
센서 관측 -> 시각 정렬
시연 명령 -> 시각 정렬
시각 정렬 -> 관측과 행동 쌍 -> 정책 학습
```
센서 관측과 로봇에 보낸 시연 명령을 시각 정보와 함께 기록합니다. 입력과 명령이 시간상 어긋나면 모델은 다른 장면의 행동을 정답으로 배우게 됩니다.

## interface | 같은 숫자라도 명령의 뜻이 다릅니다

| 기록할 약속 | 예 | 다르면 생기는 문제 |
|---|---|---|
| 행동 종류 | 위치, 속도, 이동량 | 다른 운동을 실행 |
| 좌표계 | 로봇 기준, 손끝 기준 | 방향이 달라짐 |
| 단위 | 미터, 라디안 | 크기가 달라짐 |
| 주기 | 명령 간 시간 | 같은 이동량의 속도가 달라짐 |

## shift | 작은 실수가 다음 입력을 바꿉니다

```flow LR
익숙한 관측 -> 작은 행동 오차 -> 낯선 다음 관측 -> 추가 오차
낯선 다음 관측 -> 전문가 교정 -> 복구 시연 수집
```
성공 경로뿐 아니라 정책이 실제로 만난 복구 상황을 기록하는 이유입니다.
