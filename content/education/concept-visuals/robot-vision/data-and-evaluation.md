## coverage | 수집할 다양성을 먼저 펼쳐 봅니다

```tree
촬영 계획
  물체 | 종류, 제품, 방향
  장면 | 배경, 조명, 카메라
  가림 | 손, 다른 물체, 화면 경계
  실행 | 접근, 접촉, 실패와 복구
```
거의 같은 프레임을 늘리는 것과 새 조건을 수집하는 것은 다릅니다.

## splits | 프레임보다 촬영 묶음을 기준으로 나눕니다

```tree list
촬영 세션별 분할
  훈련 세션 | 모델의 가중치 학습
  검증 세션 | 설정과 모델 선택
  시험 세션 | 최종 평가에만 사용
```
시험 장면의 이웃 프레임이 훈련에 들어오지 않도록 분할 단위를 확인합니다.

## metrics | 인식과 작업 지표가 가리키는 실패가 다릅니다

| 지표 | 확인할 실패 | 함께 볼 자료 |
|---|---|---|
| 정밀도 | 물체가 아닌 것을 검출 | 잘못 고른 후보 이미지 |
| 재현율 | 실제 물체를 놓침 | 작은 물체와 가림 사례 |
| 위치·마스크 품질 | 경계나 중심이 어긋남 | 실제 접촉 부위 |
| 작업 성공률 | 인식 이후에도 실패 | 접근, 집기, 배치 영상 |
