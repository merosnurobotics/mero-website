## clip-dino | 표현의 이름보다 어떤 관계를 배웠는지 봅니다

| 표현 계열 | 학습에 쓰는 관계 | 후속 평가의 질문 |
|---|---|---|
| CLIP | 이미지와 설명의 연결 | 말로 지정한 개념과 맞는가 |
| DINO 계열 | 이미지 관측 사이의 관계 | 부분과 물체 차이가 남는가 |
| 작업별 특징 | 목표 작업의 정답 | 실제 실패를 줄이는가 |

표현이 유용해도 미터 단위 위치와 행동은 별도로 연결해야 합니다.

## grounding | 단어를 현재 장면의 대상으로 좁힙니다

```flow LR
빨간 컵 지시 -> 후보 영역 비교 -> 선택한 컵 영역 -> 위치 확인
현재 카메라 -> 후보 영역 비교
```
같은 종류의 컵이 여러 개면 색, 위치 관계, 주변 맥락을 구분해야 합니다.

## affordance | 손잡이가 보여도 잡을 수 있는지는 별도입니다

```flow LR
손잡이 후보 -> 폭과 자세 확인 -> 도달 범위 확인 -> 접근 공간 확인 -> 행동 선택
```
로봇 손의 크기와 주변 장애물이 행동 가능성을 바꿉니다. 의미를 아는 것과 실행할 수 있는 것을 연결하는 과정입니다.
