## continuous | 장면 이해와 연속 행동 생성의 연결

```flow LR
이미지와 지시 -> 시각 언어 표현 -> 행동 생성 -> 연속 행동 청크
로봇 상태 -> 행동 생성
```
π0 계열을 읽는 개념도입니다. 입력과 출력의 정확한 구성은 모델 버전별로 확인합니다.

## open-world | 새 집에서 달라지는 조건을 펼쳐 봅니다

```tree
새 환경의 변화
  장면 | 배경, 조명, 카메라 배치
  물체 | 모양, 재질, 손잡이
  공간 | 수납 위치, 접근 경로
  작업 | 정리 순서, 사용자 지시
```
한 축의 성공이 다른 모든 축의 일반화를 증명하지는 않습니다.

## availability | 발표 이름과 재현 가능한 구성을 나누어 읽습니다

| 확인 대상 | 필요한 정보 |
|---|---|
| 연구 발표 | 과제, 평가 조건, 사람 개입 |
| 공개 코드 | 지원하는 모델과 실행 절차 |
| 체크포인트 | 몸체, 데이터, 입출력 계약 |
| 실행 시스템 | 카메라, 제어 주기, 외부 도구 |

특정 버전의 공개 여부는 본문에 기록한 확인일과 공식 자료를 함께 봅니다.
