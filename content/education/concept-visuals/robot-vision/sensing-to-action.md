## sensors | 같은 컵을 세 종류의 정보로 읽습니다

| 입력 | 잘 보여 주는 것 | 바로 알 수 없는 것 |
|---|---|---|
| RGB | 색, 무늬, 물체 모양 | 정확한 거리와 숨은 면 |
| 깊이 | 보이는 표면의 거리 | 투명·반사 표면의 정확한 형태 |
| 관절 상태 | 로봇 몸의 자세 | 컵이 실제로 잡혔는지 |

한 센서의 빈틈을 다른 관측과 실행 결과로 확인합니다.

## viewpoints | 행동마다 필요한 시야가 달라집니다

```tree
카메라 배치
  고정 시점 | 작업대 전체와 물체 관계
  손목 시점 | 접근 중 작은 부위와 접촉 주변
  두 시점 결합 | 전체 위치와 가까운 세부 함께 확인
```
손목 카메라도 그리퍼에 가릴 수 있습니다. 성공을 가르는 순간의 시야를 확인합니다.

## loop | 접근 뒤에도 목표가 같은 곳에 있는지 봅니다

```flow LR
컵 관측 -> 접근 -> 새 화면 확인 -> 위치 수정 -> 집기 확인
```
명령을 보낸 기록과 집기에 성공한 증거를 구분합니다. 새 관측은 다음 행동을 바꾸는 정보입니다.
