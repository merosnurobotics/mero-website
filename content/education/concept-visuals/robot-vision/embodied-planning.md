## hierarchy | 긴 목표와 짧은 움직임은 다른 시간 범위입니다

```tree
회의실 정리
  컵 모으기 | 대상과 순서 선택
    접근, 집기, 운반, 놓기
  종이 정리 | 묶을 위치 결정
    잡기, 옮기기, 정렬
```
계층은 역할을 이해하는 개념도입니다. 실제 시스템이 반드시 두 개의 모델로 구현되지는 않습니다.

## spatial | 다음 행동 전에 충족할 조건을 봅니다

```flow LR
컵을 상자에 넣기 -> 상자 열림 확인 -> 빈 공간 확인 -> 접근 경로 확인 -> 실행
```
보이지 않는 공간은 확인되지 않은 상태로 남깁니다. 명령의 가능 여부를 물체 이름만으로 판단하지 않습니다.

## progress | 명령 완료와 작업 성공은 다른 사건입니다

| 남길 정보 | 예 | 다시 확인할 이유 |
|---|---|---|
| 계획 | 컵을 상자에 넣기 | 장면이 바뀔 수 있음 |
| 실행 기록 | 그리퍼 닫힘 | 컵을 놓쳤을 수 있음 |
| 관측 증거 | 컵이 함께 이동 | 실제 집기 여부 확인 |
| 진행 상태 | 배치 후 컵이 상자에 남음 | 다음 하위 작업 선택 |

최신 관측이 과거 기억과 다르면 계획을 갱신합니다.
