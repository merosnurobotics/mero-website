## bridge | 이미지와 지시가 행동 출력으로 만납니다

```flow LR
카메라 이미지 -> 시각 특징 -> 시각 언어 모델
언어 지시 -> 시각 언어 모델
시각 언어 모델 -> 행동 토큰 -> 로봇 명령
```
OpenVLA 원 모델의 개념 흐름입니다. 마지막 변환에 로봇별 행동 약속이 필요합니다.

## tokens | 토큰을 로봇이 읽을 수 있는 값으로 되돌립니다

```flow LR
예측한 토큰 -> 수치 구간 해석 -> 정규화 복원 -> 좌표와 단위 확인 -> 실행
```
구간화 해상도와 실행 주기는 실제 움직임의 정밀도에 영향을 줍니다.

## adaptation | 성공 영상에서 확인할 학습 조건

| 표현 | 확인할 질문 |
|---|---|
| 사전학습 | 어떤 로봇과 작업의 경험을 썼는가 |
| 미세조정 | 새 환경 시연을 얼마나 추가했는가 |
| 제로샷 | 어떤 물체·지시·로봇에 대해 추가 학습이 없었는가 |
| 평가 성공 | 반복 횟수와 초기 조건은 무엇인가 |

이 조건이 달라지면 영상 속 성공을 같은 능력으로 비교하기 어렵습니다.
