## identify | 입력과 반응을 맞춰 모델을 보정합니다

```flow LR
실물 입력 -> 반응 측정
반응 측정 -> 모델 보정
모델 보정 -> 별도 검증
```

시간과 단위를 맞춘 뒤 비교합니다. 보정에 쓰지 않은 데이터에서도 확인하세요.

## randomization | 보정과 랜덤화가 답하는 질문

| 방법 | 중심 질문 | 근거 |
|---|---|---|
| 시스템 식별 | 평균적인 반응을 설명하나 | 실물 입력·출력 |
| 랜덤화 범위 | 어떤 변동을 경험해야 하나 | 관측한 차이·운용 범위 |
| 변화 시점 | 언제 값이 달라지는가 | 현상의 시간 구조 |

## umv-loop | UMV 사례에서 따라갈 학습과 수정의 순환

```flow LR
가상 학습 -> 실물 시험
실물 시험 -> 차이 관찰
차이 관찰 -> 모델 수정
모델 수정 -> 가상 학습
```

RAI의 공개 회고를 교육용 흐름으로 정리했습니다. 특정 훈련 횟수나 성공률을 뜻하지 않습니다.
