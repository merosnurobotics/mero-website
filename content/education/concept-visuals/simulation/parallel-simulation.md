## many-worlds | 독립된 경험을 모아 정책을 갱신합니다

```flow LR
가상 환경 A -> 경험 묶음
가상 환경 B -> 경험 묶음
경험 묶음 -> 정책 갱신
```

A와 B는 별도 상태를 가진 실험입니다. 한 화면에 보인다고 서로 충돌하는 같은 세계는 아닙니다.

## data-pipeline | 물리 엔진 밖에도 시간이 쓰입니다

```flow LR
물리 갱신 -> 관측 생성
관측 생성 -> 정책 추론
정책 추론 -> 경험 수집
경험 수집 -> 학습 갱신
```

보상·종료·초기화와 장치 사이 데이터 이동도 전체 비용에 포함합니다.

## meaningful-scale | 규모를 늘릴 때 나눠 기록할 지표

| 지표 | 답하는 질문 | 비교 조건 |
|---|---|---|
| 처리량 | 경험을 얼마나 모았나 | 환경 수·장면 |
| 지연 | 한 결과가 얼마나 늦나 | 묶음·데이터 이동 |
| 학습 성능 | 과제를 얼마나 잘하나 | 평가 조건·경험 수 |
| 실물 전이 | 실제 행동이 유지되나 | 센서·구동·환경 |
