## two-clues | 서로 다른 운동 단서가 하나의 추정으로 모입니다

```flow LR
연속 영상 -> 장면 변화
IMU 측정 -> 빠른 운동 단서
장면 변화 -> 포즈 추정
빠른 운동 단서 -> 포즈 추정
```

카메라는 공간 구조와의 관계를, IMU는 짧은 시간의 운동 변화를 보완합니다. 어느 센서도 모든 상황의 절대 위치를 직접 주지는 않습니다.

## calibration-time | 두 센서가 같은 운동을 설명하도록 맞춥니다

```tree
카메라와 IMU 연결
  내부 보정 | 픽셀과 시선
  외부 보정 | 센서 사이 위치·방향
  시간 정렬 | 각 측정의 유효 시각
```

같은 장치 안의 센서도 중심·축·시각이 다릅니다. 빠른 회전은 작은 시간 오차를 크게 드러낼 수 있습니다.

## scale-init | 거리의 기준과 초기 상태를 따로 확인합니다

| 필요한 정보 | 없으면 생기는 문제 | 확인할 근거 |
| --- | --- | --- |
| 거리 스케일 | 영상만으로 크기 모호 | 깊이·기준 간격·관성 운동 |
| 중력과 편향 | 예측이 지속적으로 어긋남 | 초기화와 운동 조건 |
| 연속 입력 | 추적이 끊기거나 늦어짐 | 누락·최대 지연 |

각 시스템이 어떤 입력을 받는지 먼저 표시합니다. 초기화 실패와 주행 중 추적 실패도 구분합니다.
