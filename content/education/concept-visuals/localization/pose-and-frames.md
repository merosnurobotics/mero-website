## reference | 센서에서 본 점을 지도에 놓기 위한 연결

```flow LR
센서 좌표 -> 몸체 좌표: 장착 변환
몸체 좌표 -> 지도 좌표: 로봇 포즈
지도 좌표 -> 지도 위 물체
```

각 화살표는 해당 방향의 좌표 변환을 뜻합니다. 로봇이 움직이면 장착 변환은 고정되어도 로봇 포즈는 바뀝니다.

## map-odom-base | 전역 보정과 로컬 이동을 다른 관계에 둡니다

```flow LR
map -> odom: 전역 보정
odom -> base_link: 연속 이동
base_link -> sensor: 장착 관계
```

일반적인 ROS 좌표계 연결입니다. 전역 보정으로 map 기준 포즈가 바뀌어도 물리적 순간 이동을 뜻하지 않습니다.

## time | 과거 관측에는 그 시각의 변환이 필요합니다

| 값 | 나타내는 순간 | 어긋날 때의 문제 |
| --- | --- | --- |
| 센서 timestamp | 실제로 측정한 때 | 장면과 운동 불일치 |
| 수신 시각 | 프로그램이 받은 때 | 통신 지연 포함 |
| 변환 시각 | 좌표 관계가 유효한 때 | 물체 위치가 틀어짐 |

빠른 회전에서만 오류가 커진다면 공간 보정뿐 아니라 시간 정렬도 확인합니다.
