## verify | 비슷한 장면에서 실제 재방문으로 확인하는 과정

```flow LR
현재 장면 -> 과거 후보 검색
과거 후보 검색 -> 기하 검증
기하 검증 -> 루프 관계
루프 관계 -> 지도 조정
```

검색은 가능성을 제안합니다. 반복되는 문이나 복도를 같은 장소로 잘못 연결하지 않도록 검증이 필요합니다.

## graph | 재방문 간선이 시간상 떨어진 포즈를 연결합니다

```flow LR
포즈 A -> 포즈 B: 이동
포즈 B -> 포즈 C: 이동
포즈 C -> 포즈 D: 이동
포즈 A --> 포즈 D: 재방문
```

점선은 시간순 이동과 다른 추가 관계를 뜻합니다. 여러 상대 관계가 함께 맞도록 포즈를 조정합니다.

## evaluate | 루프 전후에서 확인할 세 가지 변화

| 변화 | 뜻할 수 있는 것 | 검증 |
| --- | --- | --- |
| 지도 포즈의 점프 | 전역 좌표 보정 | 물리 이동과 구분 |
| 벽 정렬 개선 | 누적 오차 감소 | 외부 기준과 비교 |
| 지도의 왜곡 | 잘못된 루프 가능성 | 연결 관측 재확인 |

보기 좋은 결과뿐 아니라 거짓 루프, 보정 지연, 제어에 전달되는 연속성을 확인합니다.
