## A VLA의 출력은 답변이 아니라 행동이다

**VLA(Vision–Language–Action)**는 시각 정보와 언어 지시를 받아 로봇 행동을 만드는 모델 계열입니다. “빨간 물체를 왼쪽에 놓아”라는 지시와 장면을 입력받아 손·관절·그리퍼의 다음 움직임을 출력합니다. 구체적인 입력·출력은 모델과 로봇마다 다릅니다.

| 이름 | 주로 하는 일 | 로봇에서 읽을 것 |
|---|---|---|
| VLM | 사진과 언어를 연결해 설명·판단 | 설명 문장이 곧 모터 명령은 아님 |
| VLA | 사진·언어 조건으로 행동 생성 | 출력 행동의 단위·순서·실행 방식 |
| 행동 복제 | 시연의 상태·행동 관계를 학습 | 사람이 보여준 행동을 어느 조건에서 재현하는가 |
| 강화학습 | 행동의 결과와 보상으로 정책 개선 | 무엇을 보상하고 어떤 조건에서 평가하는가 |

VLA는 흔히 시연 데이터로 학습하거나 미세조정합니다. RL을 반드시 써야 VLA가 되는 것은 아닙니다. 반대로 신경망으로 관절을 제어해도 언어·시각 조건이 없다면 그 자체를 VLA라고 부르지는 않습니다.

## B 사진·지시·로봇 상태의 역할을 나눈다

사진은 물체와 장면을, 언어는 지금 원하는 일을 나타냅니다. 로봇 상태는 팔이 현재 어디에 있는지와 그리퍼가 열려 있는지 같은 정보를 줍니다. 모든 VLA가 같은 상태 입력을 쓰는 것은 아니므로, 선택한 모델의 입력 계약을 확인합니다.

```flow LR
카메라 관측 -> VLA 입력: 물체와 장면
언어 지시 -> VLA 입력: 대상과 목적지
관절과 그리퍼 상태 -> VLA 입력: 현재 로봇 상태
VLA 입력 -> 행동 출력: 다음 움직임
```

같은 사진에 “빨간 것을 잡아”와 “파란 것을 잡아”를 넣었을 때 행동이 달라져야 언어 조건을 활용한다고 볼 근거가 생깁니다. 여러 지시가 붙어 있어도 모두 같은 대상·같은 행동이면 언어를 무시해도 과제를 성공할 수 있습니다.

시각과 상태의 시각도 중요합니다. 사진은 물체를 움직이기 전인데 관절 값은 움직인 뒤라면 하나의 상태처럼 합칠 수 없습니다. **관측 시각·명령 시각·실행 지연**을 함께 읽는 이유입니다.

## C 행동 벡터의 뜻을 먼저 정의한다

VLA 출력은 모델마다 관절 목표, 관절 변화량, 손끝 이동·회전, 그리퍼 명령 등으로 정의됩니다. 배열 길이가 같아도 뜻이 같지는 않습니다. 손끝 목표를 관절 목표로 바꾸려면 별도의 기구학·제어 단계가 필요할 수 있습니다.

| 행동 표현 | 현재 관절 0.4 rad, 출력 0.1일 때 | 구분할 것 |
|---|---|---|
| 절대 관절 목표 | 목표 0.1 rad | 영점·관절 순서 |
| 관절 변화량 | 목표 0.5 rad | 누적 방식·한 스텝 시간 |
| 정규화한 행동 | 아직 실제 각도를 모름 | 학습 데이터의 정규화 해제 |
| 손끝 이동 | 관절 각도로 바로 읽을 수 없음 | 기준 좌표계·IK·회전 표현 |

예를 들어 실제 범위 0~1 rad를 −1~1로 정규화했다면 출력 0은 0.5 rad입니다. 다른 범위나 방식에는 이 변환을 그대로 쓰지 않습니다. 모델을 바꿀 때 가중치뿐 아니라 행동의 의미도 바뀔 수 있습니다.

## D 시연은 정답 행동이 붙은 시간 기록이다

시연 데이터는 성공 장면의 사진 모음이 아닙니다. 관측·언어·로봇 상태·행동이 시간축으로 연결된 **에피소드**입니다. 행동 복제는 이 상태에서 시연자가 선택한 행동을 맞추도록 학습합니다.

카메라 영상 100장을 가지고 있어도 대응하는 행동이 없으면 행동 복제의 정답이 없습니다. 실제 관절 측정값과 내려보낸 목표 명령도 구분합니다. 같은 시각의 측정 관절 값을 다음 목표 명령처럼 저장하면 다른 문제를 학습하게 됩니다.

```flow LR
시연 관측 -> 입력 구성: 사진과 상태와 지시
기록된 행동 -> 정답 구성: 단위와 시각 정렬
입력 구성 -> 정책 학습: 정답 행동과 비교
정답 구성 -> 정책 학습: 행동 손실
정책 학습 -> 실제 수행 평가: 새로운 시작과 장면
```

데이터 수집 장치의 구현은 프로젝트에서 정합니다. 교육에서는 데이터 한 구간을 읽고 “이 사진에 대응하는 행동이 무엇이며 언제 적용되는가”를 설명할 수 있으면 됩니다.

## E 행동 청크와 재계획을 구분한다

**행동 청크(action chunk)**는 미래 행동 여러 개를 한 번에 출력하는 것입니다. 설명용으로 제어가 50 Hz이고 청크가 10개면 계획한 구간은 0.2초입니다. 10개를 항상 전부 실행해야 하는 것은 아닙니다.

처음 5개만 실행한 뒤 새 관측으로 다시 계획하면 변화에 더 빨리 대응할 수 있습니다. 반대로 긴 청크를 그대로 실행하면 추론 횟수는 줄지만 오래된 관측을 더 오래 사용할 수 있습니다. 청크 길이·실행 길이·추론 지연은 서로 다른 값입니다.

**ACT**는 행동 청크를 예측하는 모방학습 방법입니다. 표준 ACT를 언어 조건 VLA로 설명하지 않습니다. ACT는 데이터·로봇 연결을 읽는 비교 기준이 될 수 있고, SmolVLA 등은 시각·언어 조건의 행동 생성을 학습하는 별도 모델입니다. 모든 모델을 필수로 배우기보다 입력과 행동의 차이를 비교합니다.

## F 학습 손실과 과제 성공은 다른 지표다

시연 행동과 가까운 예측을 만드는 것은 필요하지만, 실제 수행에서는 작은 오차가 다음 관측을 바꿉니다. 학습 데이터에 없던 위치로 벗어나면 오차가 계속 쌓일 수 있습니다. 이것이 저장 사진의 평가와 **닫힌 고리 수행**을 나누는 이유입니다.

같은 시연의 이웃 프레임을 train과 test로 무작위 분리하면 장면이 거의 같습니다. 에피소드·물체·배치·지시 조건을 나눠 새 조건에서 무엇을 평가했는지 적습니다. 새로운 물체를 평가한 것과 같은 물체의 새 시작 위치를 평가한 것은 다릅니다.

| 확인하려는 것 | 비교 |
|---|---|
| 언어를 활용하는가 | 같은 장면에 대상·목적지 지시만 변경 |
| 특정 시연을 외웠는가 | 새 시작 위치·배치의 같은 과제 |
| 행동 형식이 맞는가 | 단위·관절 순서·정규화 해제 후 목표 |
| 닫힌 고리에서 수행하는가 | 접근·잡기·이동·놓기의 단계별 실패 |

특정 조건의 성공률만으로 일반적인 언어 이해나 다른 로봇에서의 동작을 주장하지 않습니다. 언어 없는 기준 정책, 고정된 동작과 같은 평가 조건에서 비교하면 VLA가 추가로 해결한 문제를 읽을 수 있습니다.

## G RB-Y1에서는 모델과 구동기 사이의 연결이 필요하다

RB-Y1의 SDK는 상태와 명령을 주고받는 인터페이스입니다. VLA 모델의 출력이 그 인터페이스의 명령과 자동으로 일치하지는 않습니다. 사용하는 모델·팔·그리퍼·카메라와 행동 표현을 정해 변환해야 합니다.

```flow LR
사진과 지시와 상태 -> VLA 정책: 행동 생성
VLA 정책 -> 행동 변환: 정규화와 순서와 좌표
행동 변환 -> 로봇 제어 인터페이스: 목표와 실행 시간
로봇 제어 인터페이스 -> RB-Y1: 실제 구동
RB-Y1 -> 사진과 지시와 상태: 새 관측
```

교육 단계에서는 **측정 상태·목표 명령·실제 도착**을 구분하고, 한 팔의 입력과 행동 표를 읽습니다. 어댑터 작성, 시연 장치 연결, 보유 그리퍼 설정과 실제 로봇 실행은 프로젝트에서 담당합니다. 다른 로봇으로 학습한 정책을 RB-Y1에 그대로 꽂아 사용할 수 있다는 전제는 두지 않습니다.

공식 SDK가 명령 전송을 제공한다는 것과 VLA 제어가 장비에서 검증됐다는 것은 다릅니다. 이 자료의 RB-Y1 연결은 개념 설명이며 실물 실행 결과가 아닙니다.

## H 교육이 끝나는 지점과 프로젝트가 시작되는 지점

| 교육에서 이해할 것 | 프로젝트에서 정하고 만들 것 |
|---|---|
| VLA·VLM·행동 복제의 차이 | 사용할 모델과 기준 정책 |
| 상태·행동·시간의 계약 | 카메라·그리퍼·SDK 어댑터 |
| 시연과 데이터 분리의 의미 | 과제별 시연 수집·정리 |
| 행동 청크와 지연 | 실행 주기·청크 운영 방식 |
| 언어 활용과 수행 평가 | 팀의 물체·지시·평가 조건 |

다음으로는 행동 표현·시연 시간 정렬·언어 조건 평가를 각각 작은 비교 자료로 보강할 수 있습니다. 양팔·이동 조작이나 대형 모델 전체 학습은 이 입문의 필수 범위에 넣지 않습니다.
