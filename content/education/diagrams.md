## A 목표 속도와 실제 속도를 비교하는 피드백
```flow TB
목표 속도 -> 오차 계산: 원하는 값
엔코더 -> 오차 계산: 실제 속도를 뺀다
오차 계산 -> PID: 목표와 측정값의 차이
PID -> 모터: 보정한 출력
모터 -> 엔코더: 실제 회전량
```

## B 사진과 정답으로 모델을 학습하는 과정
```flow TB
학습 사진 -> 신경망: 픽셀 값
신경망 -> 정답과 비교: 예측한 영역
정답과 비교 -> 가중치 수정: 손실의 미분
가중치 수정 -> 신경망: 다음 예시로 반복
```

## C 경험으로 제어 정책을 학습하는 과정
```flow TB
물리 환경 -> 정책: 몸 상태 관측
정책 -> 물리 환경: 관절 목표 보정
물리 환경 -> 경험 기록: 다음 관측과 보상
경험 기록 -> PPO: 여러 시도의 기록
PPO -> 정책: 가중치 수정
```
