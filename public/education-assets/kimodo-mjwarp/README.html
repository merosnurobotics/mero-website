담긴 사례

영어 문장 하나로 NVIDIA 공식 Kimodo 데모에서 G1 모션을 생성했습니다. 이 모션의 한 발 자세를 Microban에 맞춘 뒤 Native MuJoCo CPU에서 PPO 460회, MuJoCo Warp GPU에서 PPO 120회를 학습했습니다. 최종 정책은 새 64개 초기 조건에서 GPU와 Native MuJoCo 모두 64/64를 통과했습니다.

영상은 NVIDIA의 공식 소개 영상, 문장으로 생성한 G1 Reference motion, 최종 정책의 실제 MuJoCo Warp GPU rollout을 담습니다. 기존 실험의 외란 학습 전·후 비교도 함께 담았습니다. 이 두 영상은 이전 숫자 조건 참조로 학습한 Native MuJoCo 정책이며 새 문장 GPU 정책과는 별도입니다. 외란 없는 환경에서 학습한 정책은 같은 밀기에서 8.66초에 넘어졌고, 외란 학습과 균형 보정을 적용한 정책은 18초 시험을 유지했습니다.
