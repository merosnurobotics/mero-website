담긴 사례

영어 문장 하나로 NVIDIA 공식 Kimodo 데모에서 G1 모션을 생성했습니다. 2–5초의 한 발 자세를 Microban에 맞추고 MuJoCo Warp GPU에서 PPO 400회, 819,200 transitions로 정책을 학습했습니다. 양발에서 왼발 지지로 전환하는 동작을 64개 초기 상태로 검증했으며 GPU와 Native MuJoCo CPU 모두 64/64를 통과했습니다.

영상은 NVIDIA 공식 소개 영상, 문장으로 생성한 G1 Reference motion, 실제 GPU 정책 실행을 담습니다.

함께 담은 파일

media는 실제 영상과 프레임, fonts는 로컬 글꼴, evidence는 생성·학습·평가 기록, code는 읽기용 소스입니다. 모델 체크포인트와 실행 환경 전체는 포함하지 않습니다.
