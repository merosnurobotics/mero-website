# GPU 형상별 1,000장 · COCO · 2026-10-13

## N장으로 학습했을 때의 성능

N은 **형상별 총 생성 장수**입니다. 학습 80%·검증 10%·시험 10%로 나눴습니다. 두 모델 모두 YOLO26n 사전학습 가중치 · 입력 320×320 · batch 8 · 30 epoch · AdamW · FP32입니다.

| 형상별 N | 총 생성 / 실제 학습 / 검증 | 학습 장치 | 공통 시험 | P | R | mAP50 | mAP90 |
|---|---|---|---:|---:|---:|---:|---:|
| 100장 | 400 / 320 / 40 | CPU | 400장 | 78.46% | 72.25% | 83.05% | 70.75% |
| 1,000장 | 4,000 / 3,200 / 400 | GPU | 400장 | 95.50% | 94.32% | 98.38% | 89.92% |

**1,000장 실험의 시험셋 400장(형상별 100장)을 두 모델 모두에 적용**했습니다. 100장 실험의 자체 시험 40장도 이 공통 시험에 포함됩니다. 같은 seed와 장면 ID를 유지해 작은 데이터셋의 장면이 큰 데이터셋에 포함됩니다. CPU/GPU 렌더·학습 장치는 다릅니다. 시험셋으로 설정을 조정하지 않았습니다.

P/R은 IoU 0.50과 F1 기준 confidence에서 계산했습니다. mAP90은 IoU 0.90의 AP를 형상별 평균낸 값입니다. 합성 시험은 한 장면에 한 목표 물체가 있으며 실사 정확도와 구분합니다.


생성: RTX 2080 Ti / OptiX / 4 workers. GPU 생성 시간에는 호스트의 동시 CAD 작업 영향이 포함되어 CPU 단독 속도 표에 사용하지 않습니다. GPU 학습의 원시 wall time에는 CPU 예약을 위한 일시 정지가 포함됩니다. 자세한 실행·성능·해시는 benchmark.json 및 COCO_VALIDATION.md를 참조하세요.
