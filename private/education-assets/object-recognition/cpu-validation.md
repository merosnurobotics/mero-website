# 합성 데이터 교육자료 · CPU 실행 검증 · 2026-10-13

> 문서의 미배포 표현은 실험 당시 상태입니다. 설치 오류와 실행 예제 수정은 이후 공개 교육 코드에 반영하는 변경으로 관리합니다.

**기존 120장 실습은 생성→분리→내보내기→두 모델 학습→시험까지 완료했습니다. Fruits-360 없는 형상 박스 디텍션 예제를 추가했고, 형상별 총 100장 실험의 시험 mAP50은 88.91%입니다. 로컬 수정만 했으며 GitHub push·웹 배포·학생 배포는 하지 않았습니다.**

## 환경과 검증 범위

- 장비: AMD Ryzen 5 3600, 물리 6코어·논리 12 threads, RAM 32 GiB, Ubuntu 22.04 계열 Linux.
- 공개 교육 저장소 HEAD `6585ea7e2ec7316d5f12b6680327abcac15821e6`와 동일한 소스를 별도 새 복제본에서 실행했습니다. 기존 데이터·가중치를 가져오지 않았습니다.
- Python 3.11.15의 새 venv를 사용했고 system-site-packages는 비활성입니다. 실제 Blender 4.2.1도 새로 내려받았습니다. 호스트 OS는 재사용했으며 새 OS/컨테이너 설치 시험은 아닙니다.
- Torch 2.10.0+cpu, torchvision 0.25.0+cpu, Ultralytics 8.4.54, BlenderProc 2.8.0. GPU를 숨겼고 생성은 명시적으로 CPU를 선택했습니다. 학습의 실제 Torch threads는 8입니다.
- 수정된 설치는 두 번째 새 venv에서 재검증했고 `pip check`가 통과했습니다. 설치 파일 다운로드는 pip 캐시를 사용할 수 있으므로 설치 시간을 네트워크 성능 지표로 제시하지 않습니다.
- 기존 렌더와 학습, 새 형상 렌더와 학습은 순서대로 실행했습니다. 아래 시간은 이 장비에서 한 번 측정한 값입니다.

기존 생성 시간에는 처음 Blender와 렌더용 의존성을 설치한 시간이 포함됩니다. 첫 사진까지 약 62.8초였고, 첫 사진부터 마지막 사진까지의 간격으로 계산한 생성 속도는 **7.88초/장**입니다. 형상 생성 시간에는 3D 물체 생성·4회 Blender 시작·정답 검사·분리·복사가 포함되며 Blender 최초 설치는 제외됩니다. 해상도와 threads가 다르므로 두 행을 과일 제거만의 속도 차이로 해석하지 않습니다.

학습 시간에는 학습 중 검증과 마지막 best.pt 검증이 포함됩니다. 기존 두 행은 `/usr/bin/time`의 전체 Python 명령 실행 시간입니다. 신규 행은 `model.train()` 실행 시간이며 가중치 다운로드·모델 초기화 0.45초와 프로세스 import 시간은 별도입니다. 신규 전체 train 명령은 453.85초였습니다. 형상 예제의 epoch 평균은 **14.82초**, 중앙값은 **14.92초**입니다. 생성→학습→시험 명령 전체는 **11분 9.82초**이며 환경 설치 시간은 제외합니다.

기존 1 epoch 실습은 명시한 대로 연결 확인용입니다. 과일 면 시험에는 apple·orange·plain만 있고 banana·pineapple은 없습니다. 따라서 0.797% box 점수를 5개 과일 면 전체의 정확도로 해석할 수 없습니다. 신규 실험은 작은 사전학습 detector를 사용하므로 기존 1 epoch segmentation과 성능 비교 실험은 아닙니다.

## 신규 형상별 시험 점수

| 형상 | train / val / test | Precision | Recall | mAP50 | mAP50–95 |
|---|---:|---:|---:|---:|---:|
| 큐브 (cube) | 80 / 10 / 10 | 58.64% | 50.00% | 73.30% | 73.09% |
| 정팔면체 (octahedron) | 80 / 10 / 10 | 77.21% | 67.97% | 87.45% | 87.45% |
| 정십이면체 (dodecahedron) | 80 / 10 / 10 | 100.00% | 99.57% | 99.50% | 98.00% |
| 정이십면체 (icosahedron) | 80 / 10 / 10 | 76.38% | 90.00% | 95.38% | 93.66% |
| 전체 | 320 / 40 / 40 | 78.06% | 76.88% | 88.91% | 88.05% |

Precision·recall은 Ultralytics가 confidence를 변화시키며 선택한 F1 기준 결과입니다. 단일 고정 confidence=0.25에서 센 장면 정답률이 아닙니다. mAP50은 IoU 0.5, mAP50–95는 IoU 0.5부터 0.95까지의 평가입니다. 혼동행렬 그림은 별도 기본 임계값을 사용하므로 표의 precision·recall과 직접 일치하지 않을 수 있습니다.

**큐브 recall 50%가 약점입니다.** 회전 방향에 따라 정팔면체와 혼동하는 결과와 배경 오탐을 실제 시험 그림에서 확인했습니다. 클래스당 시험 10장뿐이라 수치 변동이 큽니다. 한 장면에 한 물체가 있는 합성 시험이며 실물 사진·복수 물체·가림·목표 없는 장면의 성능을 검증한 것은 아닙니다. 과제에서는 학생들이 실패 사례를 모으고 실제 사진으로 추가 평가하도록 하는 것이 적절합니다.

기존 120장 속도·성능 수치는 공개 레시피의 원래 빈 장면 선택으로 실행한 결과입니다. 마지막 비율 수정 후 120장을 모두 재생성한 수치는 아닙니다. 수정된 선택의 실제 렌더 두 장과 120개 결정의 재현성을 따로 검증했습니다. 50,000장 GPU 전체 레시피는 이번 CPU 입문 검증 대상이 아닙니다.
