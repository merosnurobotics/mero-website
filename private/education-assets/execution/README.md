# 교육 자료 실행 이미지

2026-10-08에 기존 교육 코드를 실행해 얻은 PNG 29개와 실행 기록입니다. 각 이미지는 기존 13개 교육 자료의 해당 코드 설명 아래에 첨부되어 있습니다.

- 터미널: Xterm에서 실제 명령을 실행하고 창을 캡처했습니다. 빈 아래쪽 여백만 잘랐으며 출력 원문은 같은 이름의 TXT에 있습니다.
- RViz: 실제 ROS 메시지를 받아 표시한 창입니다. 사용한 설정을 같은 이름의 RVIZ 파일로 제공합니다. LiDAR 화면의 `pose-to-tf.py`는 추정 위치를 RViz 좌표 변환으로 전달하는 보조 노드입니다.
- 그래프: PID 계산, LiDAR 위치 추정, 물체 좌표 변환, Microban 재실행의 저장 값을 PNG로 그렸습니다. 해당 CSV/JSON을 함께 제공합니다.
- 객체인식: 저장된 모델로 실사진 4장에 추론을 실행한 결과입니다. `inference/`에 예측 기록이 있습니다.
- Microban: 저장 정책을 Native MuJoCo에서 18초, 900스텝 동안 실행했습니다. 시드 75501의 초기 상태 하나를 사용했고 외력을 추가하지 않았습니다. 0.02초, 4.50초, 13.50초의 PNG는 이 실행에서 직접 렌더링했습니다.

모터 예제는 드라이런으로 명령 전달만 확인했습니다. LiDAR와 물체 좌표 예제는 합성 입력을, PID는 설명용 입력 수열을 사용했습니다. SSH 이미지는 설정 파일 검사 결과입니다. 실제 로봇 구동, 원격 장비 접속, 모델 재학습을 수행한 기록은 아닙니다.

`manifest.json`에는 실행 명령, 원본 코드의 SHA-256, PNG의 크기와 SHA-256이 있습니다. ZIP의 `scripts/`에는 캡처와 렌더링에 사용한 두 스크립트를 포함했습니다. 재실행에는 스크립트에 지정된 실습 저장소, 모델, 입력 사진과 Python 환경이 필요합니다. 모델·입력 원본·실습 저장소 전체는 이 묶음에 포함하지 않았습니다.

MEROsite 저장소에서 다음과 같이 실행합니다. 개별 그룹은 `all` 대신 `basic`, `ros`, `perception`, `microban`을 지정합니다.

```bash
source /opt/ros/humble/setup.bash
/usr/bin/python3 scripts/capture-education-results.py all
```
